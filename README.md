# 📚 BookBuddy

BookBuddy is a modern single-page React application that allows users to browse, search, and reserve books from a digital library. Built as a full CRUD and authentication-enabled project, BookBuddy demonstrates core front-end development skills including API integration, protected routes, token management, conditional rendering, and custom UI/UX design.

---

## 🚀 Features

- 🔎 Browse and search a live catalog of books
- 📖 View book details on individual pages
- ✅ Register and login using JSON Web Tokens (JWT)
- 🔐 Protected account page showing current user and reservations
- 📚 Authenticated users can reserve and return books
- 🧼 Clean UI inspired by minimalist design
- 🔥 Responsive design with Google Fonts and Material Icons

---

## 🛠️ Tech Stack

- **Frontend**: React, React Router, CSS (custom styling)
- **API**: [FSA BookBuddy API](https://fsa-book-buddy-b6e748d1380d.herokuapp.com/api)
- **Libraries**: React Router DOM
- **Tools**: Vite, Git, GitHub
